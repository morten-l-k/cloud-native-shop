# Gemini Code Assist Prompt

You are an expert Angular developer. Your task is to build a modern, responsive e-commerce frontend for an online shop called "Cloud Native Shop".

**Project Goal:**

Create a complete e-commerce experience using Angular. The application should be well-structured, performant, and easy to maintain.

**Key Features:**

1.  **Product Discovery:**
    *   **Product Listing Page:** Display a grid or list of products with essential information (name, price, image). Implement filtering and sorting options.
    *   **Product Detail Page:** Show detailed information about a single product, including multiple images, description, specifications, and customer reviews.

2.  **Shopping Cart:**
    *   Allow users to add and remove products from their cart.
    *   Display the cart contents with quantities and subtotals.
    *   A "Proceed to Checkout" button.

3.  **User Account:**
    *   **User Profile Page:** Display user information and order history.
    *   **Authentication:** Implement user login and registration (details to be provided for the backend API).

**Technical Guidelines:**

*   **Framework:** Angular (latest stable version)
*   **Styling:** Use a modern design approach. You can use a component library like Angular Material, NG-ZORRO, or a CSS framework like Bootstrap. The design should be clean, intuitive, and responsive across all major devices.
*   **State Management:** For managing application state, especially for the shopping cart and user session, consider using a state management library like NgRx or a simpler service-based approach with RxJS `BehaviorSubject`.
*   **API Integration:** The frontend will communicate with a backend API for product data, user authentication, and order processing. All API interactions should be handled through dedicated services. Please mock the initial data until the API is ready.

**Development Process:**

1.  Start by setting up the basic project structure with components for each of the key features.
2.  Create mock data and services to simulate API responses for products and user data.
3.  Build the UI for each feature, focusing on a high-quality user experience.
4.  Implement the logic for state management and component interactions.
5.  Once the UI and frontend logic are in place, we will integrate with the actual backend APIs.

Please start by creating the initial components and services for the product listing page.
